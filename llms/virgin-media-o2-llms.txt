# Virgin Media O2

> Virgin Media O2 is the United Kingdom's converged fixed and mobile network operator, formed in 2021 as a 50/50 joint venture between Telefonica and Liberty Global. It is a GSMA Open Gateway participant that commercially launched CAMARA-standardised KYC Age Verification and KYC Tenure APIs in the UK on 23 September 2025, alongside SIM Swap. It operates no developer portal: there is no first-party API reference, no OpenAPI, no sandbox, no SDK, and no self-serve signup. Developers reach the Virgin Media O2 network-API surface only through third-party aggregators such as JT Group and TMT.ID.

## Status
- No developer portal. developer/developers/docs/api/opengateway subdomains of virginmediao2.co.uk, o2.co.uk and virginmediao2business.co.uk do not resolve; the equivalent corporate paths return 404 (probed 2026-07-25).
- No OpenAPI or Swagger document on any Virgin Media O2 host. api.o2.co.uk resolves but returns HTTP 500 to every path.
- No /.well-known/ discovery surface: no security.txt, no openid-configuration, no oauth-authorization-server, no api-catalog.
- No first-party SDK on npm, PyPI, Maven or NuGet. Both GitHub organisations (VirginMediaO2, Virgin-Media-O2) exist with 0 public repositories.
- No public webhooks, event catalog, AsyncAPI, GraphQL surface, gRPC protos, or Postman workspace.

## Network APIs (CAMARA, aggregator-only)
- [KYC Age Verification](https://github.com/camaraproject/KnowYourCustomer/blob/main/code/API_definitions/kyc-age-verification.yaml): commercially launched 2025-09-23 in the UK. Specification published upstream by the CAMARA project, not by Virgin Media O2.
- [KYC Tenure](https://github.com/camaraproject/Tenure): commercially launched 2025-09-23 in the UK.
- [SIM Swap](https://github.com/camaraproject/SimSwap/blob/main/code/API_definitions/sim-swap.yaml): available across the four UK operators prior to the 2025-09-23 launch.
- [KYC Match](https://github.com/camaraproject/KnowYourCustomer/blob/main/code/API_definitions/kyc-match.yaml): committed for end-2025; no callable Virgin Media O2 evidence as of 2026-07-25.
- Access channel: third-party aggregators (JT Group, TMT.ID). There is no Virgin Media O2 onboarding path, key issuance, sandbox, or published base URL.

## APIs served on Virgin Media O2 hosts
- [Newsroom Content API (WordPress REST)](https://news.virginmediao2.co.uk/wp-json/): anonymous read access to the Virgin Media O2 press newsroom. 253 routes; wp/v2 collections for posts, pages, media, categories and tags. The only callable, self-describing API Virgin Media O2 serves on a host it controls. Not a product API.
